# 江城智旅 · 文旅活动运营智能体（芜湖算力算法大赛 · 智能体赛道 命题02）

## 一、定位
面向城市文旅活动运营场景的 AI 运营助手，参赛 2026 长三角（芜湖）算力算法创新应用大赛 **智能体赛道·命题02「江城智旅」**。它把"活动策划辅助 / 资源智能匹配 / 文旅活动整合 / 活动效果分析"四个命题子任务，编排成一条可运行的智能体工作流，底层复用已在 SkillHub 企业团队上架、前台可见的 4 个真实技能（非概念文档，是真能跑的 prompt 工程资产）。

## 二、场景
- 文旅局/景区运营方要做一场城市文旅活动（音乐节、非遗市集、夜间经济周），需要快速产出策划方案。
- 活动执行中要把分散的场地/商户/达人/交通资源智能匹配到位。
- 活动前后要把内容一键整合到多平台（公众号/短视频/小红书），并在结束后用问卷/舆情做效果复盘。
- 与已发布技能资产直接对应：local-life-ops（本地生活操办）、travel-itinerary-planner（个性化行程）、survey-insight-analyzer（问卷访谈洞察）、content-repurposer（一鱼多吃）、competitor-teardown（竞品拆解）。

## 三、能力（对应命题四子任务）
1. **活动策划辅助**：输入城市/主题/周期/预算，产出结构化活动策划（目标人群、亮点设计、动线、风险预案）。→ 复用 travel-itinerary-planner + local-life-ops 的策划框架。
2. **资源智能匹配**：把场地/商户/达人/服务商按活动调性智能匹配打分，输出推荐清单。→ 复用 local-life-ops 的资源调度逻辑。
3. **文旅活动整合**：把策划与资源一键改写成公众号长文/短视频脚本/小红书种草，统一品牌语气。→ 复用 content-repurposer + wechat-mp-writer。
4. **活动效果分析**：收集问卷/评论/舆情，做满意度与痛点洞察，输出复盘与下场优化建议。→ 复用 survey-insight-analyzer。

## 四、技术底座
- 智能体内核：复用 `skillhub-mcp-server`（零依赖 MCP over stdio，4 工具 search_skills/get_skill/list_categories/skill_as_tool，已开源 github.com/q15004040209-creator/skillhub-mcp-server），把上述 4+ 个技能暴露为可调用 tool，由编排器按命题四步串联。
- 编排器：`wuhu_tourism_agent.py`（本包），读取已发布 SKILL.md 的 frontmatter 与工作流，按"策划→匹配→整合→分析"四阶段调用对应技能并汇总。
- 可运行验证：本地 `python wuhu_tourism_agent.py --topic "芜湖非遗夜市" --city 芜湖` 即可走通四步并生成报告（demo 模式下读取真实 SKILL.md 内容，拼装可交付文案）。

## 五、运行说明
```
# 依赖：Python 3.10+，仅需标准库（复用 skillhub-mcp-server 的零依赖设计）
python wuhu_tourism_agent.py --topic "芜湖非遗夜市周" --city 芜湖 --budget 50万 --days 7
# 输出：生成 wuhu_plan.md（策划）+ wuhu_resources.md（资源匹配）+ wuhu_content.md（多平台内容）+ wuhu_review.md（效果复盘模板）
```
- 技能源：从 SkillHub 企业团队（org 2127 / 蓝羽兴）已发布技能目录加载，确保"可运行、可展示、可验证"。
- 演示：录屏展示从输入主题到四份产物生成的全过程（≤5 分钟）。

## 六、测试样例
输入：「芜湖·长江夜游音乐节，周期 3 天，预算 80 万，目标年轻家庭+大学生」
输出框架：
- 策划：夜间动线（演出现场→非遗市集→江景打卡）→ 风险（人流超载/天气/噪音投诉预案）。
- 资源匹配：场地（滨江公园 A 区）/ 商户（3 家非遗老字号+5 家文创）/ 达人（2 位本地生活博主）/ 交通（接驳专线）。
- 内容：公众号深度长文 + 抖音 15s 悬念预告 + 小红书"打卡攻略"三件套。
- 复盘：活动后问卷模板（满意度/动线流畅度/复访意愿）+ NPS 归因。
